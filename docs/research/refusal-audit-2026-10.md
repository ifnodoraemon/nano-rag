# 拒答审计：38% 拒答里 77% 是误拒，根因是一条提示词

## 审计方法

端到端 40 条，其中 13 条拒答。对每一条拒答，把它的上下文原样交给模型，问：
"上下文里到底有没有能回答这个问题的信息？"（HAD_ANSWER / PARTIAL / NO_ANSWER）

## 结果：10/13 误拒（77%）

| 判定 | 数量 | 例子 |
| --- | --- | --- |
| **HAD_ANSWER（误拒）** | **10** | 见下 |
| NO_ANSWER（正确拒答） | 3 | 上下文为空或确实无关 |

误拒样例（左侧问题，右侧是上下文里被忽略的答案）：

| 问题 | 上下文里明明写着 |
| --- | --- |
| 男的多少岁能结婚？ | 第二条 结婚年龄，男不得早于二十周岁，女不得早于十八周岁。 |
| 厂里必须跟员工签合同吗？ | 第十七条 开发区内企业职工实行劳动合同制，企业必须与职工签订劳动合同。 |
| 打工的工资标准和奖金到底谁说了算？ | 第十八条 开发区企业职工的工资标准、工资形式和奖励、津贴制度由企业自主确定。 |
| 工会去反映问题后，有关部门多久要书面回话？ | 劳动行政部门…应当在30日内给予答复…并将处理结果书面通知工会。 |
| 光嘴上说离婚或者发消息说离婚，算不算数？ | 任何一方用口头或者文字方式通知对方离婚的，一律无效。 |
| 商家自己印代金券代替人民币流通可以吗？ | 第二十条 任何单位和个人不得印制、发售代币票券，以代替人民币在市场上流通。 |
| 饭店、酒楼还能收野味来做菜卖吗？ | 严禁饭店、宾馆、酒楼…收购、加工、制作、出售…陆生野生动物及其产品。 |
| 自己养野生动物拿去卖，要办哪些证？ | 人工繁育国家重点保护野生动物实行许可制度…取得人工繁育许可证 |
| 遇到地震洪水这种大灾，红十字一般会提前准备些啥？ | 第十四条：建立红十字应急救援体系和备灾救灾信息系统… |
| 女的多少岁能结婚？ | 结婚年龄，男不得早于二十周岁，女不得早于十八周岁。 |

这不是检索问题——答案就在上下文里，是**证据审计环节判"不充分"**。

## 根因

审计提示词的原话：

> "Decide whether the evidence can **close** the user's question... **coverage_ratio**..."

"coverage"（覆盖度）把模型引向"证据是否覆盖了问题的所有方面"，而这些问题大多只问
**一个具体事实**。证据只回答那个事实、不涉及其它方面时，模型给出低 coverage → 判不充分 → 拒答。

## 修法

把"覆盖度"改成"可回答性"，并明确举反例：

> SUFFICIENT means: the evidence contains the information needed to answer the question
> that was actually asked. It does NOT require that the evidence cover every angle of
> the topic... Example: for "男的多少岁能结婚?" the passage "结婚年龄，男不得早于二十周岁"
> is sufficient, even though it says nothing about the conditions or exceptions.

## 效果

| 指标 | 修复前 | 修复后 |
| --- | --- | --- |
| 拒答率 | 38% (15/40) | **10% (4/40)** |
| 有可靠引用 | 25/40 | **37/40** |
| **SUPPORTED（裁判）** | **32%** | **60%** |
| UNSUPPORTED（裁判） | 15% | 15% |
| REFUSED（裁判） | 38% | 8% |

**端到端正确率 32% → 60%，来自一条提示词的修正。**

## 同时修正的一个设计问题

`RAG_CANDIDATE_FILTER_ENABLED` 默认改为 **false**。该阶段要求模型返回与候选数量严格对齐的
评分数组，实测模型常返回 11 个对 12 个候选，按"No degradation paths"原则直接抛错——
结果是一个**收益未证实的辅助阶段让整个请求失败**。关闭是诚实的选择；重新启用前需要
它同时被证明"有益"和"稳健"。

## 保留意见

- 40 条样本，裁判 7 条失败（18%）。比例可信度够，精确值不可信。
- UNSUPPORTED 稳定在 15%（6 条），这是下一个要查的问题：答案有内容但上下文不支持。
